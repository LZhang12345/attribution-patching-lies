# Implementation provenance

The core API in `estimators.py` is a cleaned reference implementation of the
paper's directional Taylor formulas. Its tests use independent closed-form
quadratic and cubic functions, including isolated-versus-joint intervention
cases. MS-HVP sums local first- and second-order changes with a displacement
of `delta / K` on each segment.

The Hugging Face head adapter is adapted from the research implementation of
additive interventions at attention output projections. Tests compare its
isolated endpoints against independent replacement hooks on small GPT-2 and
grouped-query Llama models.

`mib.py` preserves the original `exact_ms_hvp_core.py` from the corrected
isolated-edge benchmark implementation. The source was taken from the
research code snapshot at commit
`8dea15d5005993e39ed223f75530e04cef6d8913`. It is included as a pure utility
module, without the cluster-specific runner. Tests cover independent batch
updates, Taylor derivatives, and Gemma endpoint normalization.

The README banner and method overview are original vector illustrations.
The cubic plot is generated by `scripts/build_readme_assets.py` from estimator
outputs, with values saved in `assets/cubic_demo.json`.

The animated explanation is generated by `scripts/build_method_animation.py`.
It uses the same cubic example and the released HVP/MS-HVP functions. The
displayed MS-HVP curve accumulates local estimated changes, with a checked
sum matching `multi_step_hvp(..., steps=5)`. The numerical coefficients and
segment contributions are saved in `assets/method_animation.json`.
